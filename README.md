* Project Description
This project represents a UML Class Diagram design for a system as part of the CSD203 SQL Databases course at Kigali Independent University (ULK).

* Business Idea & Scope
The system is designed for conference and event management, organizing data for attendees, speakers, sessions, and tickets.

* Main Classes
- Attendee: Manages participant and guest details.
- Speaker: Manages expert speakers' information.
- Session: Manages workshops and schedule timelines.
- Ticket: Manages ticket types and bookings.
